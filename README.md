# فريق agents لثيم بوش (POSH)

الريبو ده فيه إعداد Claude Code للشغل على ثيم شوبيفاي بتاع poshkw.com. الثيم نفسه موجود على شوبيفاي، والريبو فيه بس الفريق والقواعد والأدوات.

## فيه إيه

- `CLAUDE.md`: قواعد بوش اللي أي agent لازم يلتزم بيها (ممنوع النشر، ممنوع تلمس الدفع والبكسلات والمخزون، ألوان البراند، خدمة الساعتين، الخ).
- `.claude/agents/`: 15 agent متقسمين: تصميم، برمجة، جودة، مراجعة نهائية، تسويق وتتبع.
- `.claude/skills/`: طريقة الشغل الآمنة على الثيم (`posh-theme-workflow`)، قواعد العربي من اليمين (`shopify-rtl-arabic`)، ومراجعة التصميم والاختبار.
- `.claude/rules/`: قواعد عامة لكتابة ومراجعة الكود.
- `tools/`: أدوات الفحص: Theme Check على الثيم كله، فحص CSS، وتنزيل ملفات الثيم.

## الاستخدام

افتح جلسة Claude Code جديدة واختار الريبو ده، والـ agents هتبقى متاحة بالاسم. لتشغيل الأدوات:

```bash
cd tools && npm install
node theme-check.mjs <theme-folder>
node css-check.mjs <theme-folder>
```

## المصدر

الـ agents والـ skills العامة متاخدة من `amradel55/brand-creative-dashboard` (commit `6b119a7`) ومتعدّلة لثيم شوبيفاي. قواعد ومهارات بوش مكتوبة مخصوص للمشروع.
